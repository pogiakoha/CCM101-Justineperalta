# Amazon Web Services (AWS) Research Report

## Brief Overview
Amazon Web Services (AWS) is the leading public cloud platform offering over 200 fully featured services globally. It focuses on providing scalable cloud infrastructure, modern AI technologies, and open data solutions for businesses worldwide.

## Global Infrastructure
The AWS global infrastructure spans over 100+ Regions and 300+ Availability Zones (AZs). This network is engineered for ultra-low latency, high security, and high availability.

## Cloud Management Console
The AWS Management Console is a web-based portal where engineers can view and manage their entire cloud environment. AWS also provides dedicated portals for events (such as the re:Invent catalog) along with integrated tools for database management and AI monitoring.

## Four (4) Core Services
* **Amazon EC2:** Virtual compute servers designed to run scalable applications.
* **Amazon S3 & Aurora:** Scalable object storage alongside high-performance relational databases (supporting PostgreSQL/MySQL).
* **Amazon VPC:** A secure and isolated virtual network environment.
* **AWS IAM:** Identity, access control, and permissions management to safeguard resources.

## Three (3) Advantages
* **Open Data Architecture:** Offers freedom of choice in utilizing open-source tools (such as Apache Iceberg and Spark) without vendor lock-in.
* **AI and Startup Ecosystem:** Robust support, tooling, and cloud credits for organizations building AI and Machine Learning applications.
* **Seamless Migration:** Fast and direct migration path for legacy databases (SQL Server/Oracle) to managed cloud services.

## Typical Enterprise Use Cases
* Database Migration from On-Premises to the Cloud
* Enterprise Data Analytics and Open Data Lakes
* Generative AI and Machine Learning Development
