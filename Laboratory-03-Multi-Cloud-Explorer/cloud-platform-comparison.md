# Cloud Platform Comparison

## General Comparison Table

| Category | AWS | Microsoft Azure | Google Cloud Platform |
| :--- | :--- | :--- | :--- |
| **Launch Year** | 2006 | 2010 | 2008 |
| **Compute Service** | Amazon EC2 | Azure Virtual Machines | Google Compute Engine |
| **Storage Service** | Amazon S3 | Azure Blob Storage | Google Cloud Storage |
| **Networking Service** | Amazon VPC | Azure Virtual Network (VNet) | Google Cloud VPC |
| **Identity Service** | AWS IAM | Microsoft Entra ID | Google Cloud IAM |

---

## Answers

**1. Which cloud provider offers the broadest range of services?**
Amazon Web Services (AWS) offers the broadest range of services with over 200 fully featured offerings. Because of its early launch in 2006, it has had the most time to develop a vast, mature ecosystem that caters to almost every IT requirement.

**2. Which provider best integrates with Microsoft technologies?**
Microsoft Azure provides the most seamless integration with Microsoft technologies. It is natively designed to work flawlessly with enterprise staples like Windows Server, Active Directory, and Microsoft 365, making it the top choice for Microsoft-centric organizations.

**3. Which provider is strongest in Artificial Intelligence and Kubernetes?**
Google Cloud Platform (GCP) is the strongest in both Artificial Intelligence and Kubernetes. Google originally developed Kubernetes, making their managed GKE service highly advanced, and their ecosystem leads in AI innovation with tools like Vertex AI and Gemini.

**4. Which cloud platform would you personally choose and why?**
I would personally choose AWS due to its immense market share, global reach, and extensive community documentation. Learning AWS provides a highly versatile foundation for a cloud computing career since it is the most widely adopted platform by employers worldwide.
