# 🚀 Mission 1: Welcome to the Cloud

## Mission Overview
This mission introduces working within a real-world Linux Cloud environment using the KillerCoda Playground. It covers setting up a cloud terminal session, performing Linux administration and user creation, executing diagnostic commands to gather system specifications, and creating a structured portfolio directory for course activities.

---

## Objectives
* Explore and navigate a live Linux cloud environment via KillerCoda Playground.
* Perform basic user and account administration in a Linux OS.
* Execute essential Linux commands to gather system information and cloud diagnostics.
* Establish a standardized directory structure for cloud computing laboratory submissions.

---

## Activities Performed
1. **Cloud Environment Access:** Connected to and explored the live Linux cloud virtual machine environment on KillerCoda.
2. **User Administration:** Created a new custom Linux user account and set up user environment configurations.
3. **System Information & Diagnostics:** Executed Linux system commands to retrieve diagnostic details such as OS distribution, CPU specs, memory allocation, and disk usage.
4. **Portfolio Structuring:** Organized the local repository by creating the `Laboratory-01-Welcome-to-the-Cloud` directory to store screenshots, logs, and mission outputs.

---

## Linux Commands Used
Below are the key Linux commands executed during the mission:

* `whoami` — Displays the current logged-in username.
* `uname -a` — Displays system kernel, architecture, and OS details.
* `hostnamectl` — Displays detailed host name, OS version, and kernel information.
* `lscpu` or `cat /proc/cpuinfo` — Displays CPU hardware architecture and details.
* `free -h` — Checks total, used, and available system RAM in human-readable format.
* `df -h` — Displays disk space usage across all mounted filesystems.
* `useradd` / `adduser` — Creates a new user account in Linux.
* `mkdir` — Creates directories and folder structures.
* `ls -la` — Lists files and directories, including hidden ones, with detailed permissions.
